# Palette rationale

The six daypart palettes of SPEC §6.2 — late night, dawn, morning, afternoon,
evening, night — each with its mode or scale family, register range, brightness,
reverb size and instrument set, plus the reasoning behind each choice and what the
weather modifiers do to it.

Authoritative values live in `config/score.yaml`. This file explains *why* they are
what they are, so a future tuning session does not undo a deliberate choice by
accident.

*To be written by `music-director` in Phase 2, when daypart palettes are built. Phase
1 uses a single provisional palette.*
