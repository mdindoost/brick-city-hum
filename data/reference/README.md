# Reference library — permanent, curated recordings

These slices are **never deleted** (SPEC §3.5, §11.3). They exist because an A/B test
is only meaningful on identical input: comparing palette A heard at 2 p.m. against
palette B heard at 4 p.m. compares two different cities, not two palettes. The same
slices, rendered forever, are also how a regression is diagnosed — they answer "did
the music change, or did the city?".

A 30-minute slice is roughly 1 MB gzipped, so the whole library costs about 10 MB for
the life of the project.

## What goes here

8–10 deliberately chosen 30-minute slices, each capturing a genuinely different city:

- [ ] a busy weekday morning
- [ ] a dead 3 a.m.
- [ ] a thunderstorm (SPEC §6.7 rare moment)
- [ ] a snow day
- [ ] a holiday
- [ ] a summer evening
- [ ] a day with the EWR runway flow reversed
